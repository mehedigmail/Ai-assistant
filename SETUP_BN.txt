REAL MARKET SIGNAL BOARD — MULTI-USER + 48-HOUR ACCESS

এই সংস্করণে Market Payout Control বাদ, Technical Score /9 থেকে 100-এ স্বাভাবিকীকরণ, Device Access API এবং বাধ্যতামূলক মেয়াদ-শেষ Popup যুক্ত আছে।

RENDER-এ প্রয়োজনীয় Environment Variables:
1) TWELVE_DATA_API_KEY = আপনার Twelve Data API key
2) DATABASE_URL = Render PostgreSQL-এর Internal Database URL (যদি Render একই region-এ থাকে)
3) NODE_ENV = production

গুরুত্বপূর্ণ:
- PostgreSQL ছাড়া সার্ভার চালু হবে না; কারণ ৪৮ ঘণ্টার ডিভাইস রেকর্ড স্থায়ীভাবে সংরক্ষণ করতে হবে।
- Render PostgreSQL তৈরি করে DATABASE_URL যুক্ত করুন। DATABASE_SSL=false দেবেন না, যদি না আপনার DB provider স্পষ্টভাবে SSL বন্ধ রাখতে বলে।
- Facebook প্রোফাইল URL এবং কাস্টম Popup লেখা পরে server.js/html-এ কনফিগার করা যাবে। এই ZIP-এ Facebook লিংক এখনো placeholder/hidden।
- Password/OTP ছাড়া Browser cookie-ভিত্তিক ডিভাইস চেনা যায়। ব্যবহারকারী cookie/site data মুছে ফেললে বা অন্য browser/device profile ব্যবহার করলে নতুন পরিচয় তৈরি হতে পারে; শতভাগ device lock সম্ভব নয়।
- Render-এর একাধিক instance চালালে shared scan cache/lock-কে PostgreSQL-এ স্থানান্তর করতে হবে; এই সংস্করণ একক app instance-এ in-process scan coalescing/cache ব্যবহার করছে।
- Twelve Data plan-এর API quota এবং Render CPU/RAM-এর ওপর concurrent user capacity নির্ভর করবে; নির্দিষ্ট user সংখ্যা নিশ্চিত নয়।

Deploy: ZIP extract করে পাঁচটি app file ও SETUP_BN.txt GitHub repo-তে আপলোড করুন; package.json পরিবর্তনের পর Render build/deploy হবে।
